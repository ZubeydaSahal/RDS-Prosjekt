# RDS-Prosjekt

**Kjøre programmet:**
- Åpne mappen

*- Kjør frontend:*
cd rds-app
npm run dev

*- Kjør backend:*
cd rds-backend 
./mvnw spring-boot:run

**Åpne webapplikasjonen**
*Kjører som regel på "http://localhost:5173/"*

<img width="331" height="143" alt="image" src="https://github.com/user-attachments/assets/690c01aa-5fb7-42eb-b5ff-3e18764b1e8b" />
 


**Steg for steg bruk av systemet**
1.	Når applikasjonen er startet kan du enten:
-	Laste opp en RDS fil fra menyen 
-	Skrive inn RDS skript direkte i tekstboksen 
 
<img width="209" height="191" alt="image" src="https://github.com/user-attachments/assets/fa5e47ff-43f4-4539-a2c6-61756b111402" />




For å visualisere skriptet kan du trykke på Build Graph knappen eller trykke Ctrl+Enter.
 
<img width="399" height="141" alt="image" src="https://github.com/user-attachments/assets/e3ef02e0-1886-492f-8952-981306f534cb" />

Etter visualisering er generert kan du bruke ulike filtre for å skjule eller vise deler av treet. Filtreringen skjer automatisk, så du trenger ikke å trykke på en ekstra knapp for å oppdatere visningen. 
 
<img width="442" height="201" alt="image" src="https://github.com/user-attachments/assets/994a8179-8e16-4c6b-9e57-f4a7101a0e2e" />


Når du er ferdig med skriptet og visualisering kan du:
-	Laste ned skriptfilen 
-	Laste ned et bilde av visualisering
